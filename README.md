# Ashlee Seagle | Developer Portfolio

A modern developer portfolio built with Vue 3, TypeScript, and Tailwind CSS showcasing professional software engineering work, reusable frontend architecture, and personal projects.

🌐 **Live Site:** https://developer-portfolio-brown-gamma.vercel.app/

---

## About

This portfolio highlights a collection of professional and personal projects focused on frontend engineering, user experience, and reusable application architecture.

Featured work includes:

- Enterprise Event Management Platform
- Reusable Frontend Platform
- AI-powered Workout Planner
- Additional frontend projects and case studies

The goal of this portfolio is to demonstrate real-world software development experience through polished project showcases rather than simple project galleries.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/ashlee-seagle/developer-portfolio.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
